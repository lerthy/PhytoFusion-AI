# Glossary

| Term | Meaning |
|---|---|
| Host | Plant that would receive the genetic change (*S. baicalensis*) |
| Donor | Plant providing the candidate gene (*S. barbata*) |
| Assembly | A reference genome sequence, identified by an accession such as GWHAOTO00000000 |
| GFF3 | File format listing gene positions and annotations |
| Ortholog | Genes in different species that descend from a common ancestral gene |
| Synteny | Conserved gene order between genomes |
| KPS | Kaurene/clerodane-related diterpene synthase family (SbarKPS1, SbarKPS2, SbaiKPS1) |
| Flavonoid | Class of plant compounds including baicalein, baicalin and wogonin |
| Clerodane diterpenoid | Compound class associated with *S. barbata* |
| PAL, CHS, 4CL, CHI, CYP82D | Enzyme families in flavonoid biosynthesis |
| CRISPR | Genome editing technique. Here it is simulated only |
| GeneBridge | Our assessment engine that links genomic evidence to hypothetical engineering |
| Evidence class | strong, moderate or limited. Describes support for a claim, not success odds |
| RAG | Retrieval-augmented generation: an LLM answers using retrieved sources |
| RLS | Postgres row-level security |
